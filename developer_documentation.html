1. Overview

The La Rose Noire Facilities Portal is a lightweight, high-performance web dashboard operating strictly on native HTML5, Vanilla Javascript, Tailwind CSS (for aesthetics), and raw PHP serving as the backend layer.

A core philosophy of this portal is No-SQL operation. The architecture fundamentally diverges from traditional MySQL implementations and leverages flattened JSON arrays stored safely in a local /data directory to facilitate configurations.

4. Code Snippets Reference

The backend heavily depends on clean PHP read/writes for REST-like state management. Below represents the universal app writing method inside save_app.php.

api/save_app.php (Excerpts)
<?php
header('Content-Type: application/json');

// Disable display of errors to prevent JSON corruption
error_reporting(E_ALL);
ini_set('display_errors', 0);
ini_set('log_errors', 1);

// Decode input payload expecting explicit JS Object -> JSON mapping
$input = json_decode(file_get_contents('php://input'), true);

try {
    // 1. Load current apps data
    $apps = json_decode(file_get_contents('../data/apps.json'), true);
    if (!$apps) $apps = [];

    // 2. Identify toggle operation constraints
    $isToggle = isset($input['isToggle']) && $input['isToggle'];

    // 3. Scan dictionary registry or index insertion points
    // Find highest order execution algorithm snippet:
    $order = isset($input['order']) && $input['order'] !== '' ? (int) $input['order'] : null;
    if ($order === null || $foundIndex < 0) {
        $maxOrder = 0;
        foreach ($apps as $app) if ($app['order'] > $maxOrder) $maxOrder = $app['order'];
        $order = $maxOrder + 1;
    }

    // 4. Update memory & sync physical file
    usort($apps, function ($a, $b) { return $a['order'] <=> $b['order']; });
    file_put_contents('../data/apps.json', json_encode($apps, JSON_PRETTY_PRINT));

    echo json_encode(['success' => true, 'message' => 'App saved successfully']);
} catch (Exception $e) {
    echo json_encode(['error' => 'Server error']);
}
?>

On the frontend, the dynamic responsive interface handles fetching without reloading leveraging Fetch promises.

portal.php - DOM Load (Excerpts)
async function loadApps() {
    try {
        const [appsRes, foldersRes] = await Promise.all([
            fetch('data/apps.json?t=' + new Date().getTime()),
            fetch('data/folders.json?t=' + new Date().getTime())
        ]);
        
        allApps = await appsRes.json();
        const folders = await foldersRes.json();

        // Execution of tailwind layouts mapped dynamically
        renderGrid(allApps, folders);
    } catch(err) {
        console.error("Portal Exception: Data tree failing to map layout", err);
    }
}

5. API Endpoint Documentation

Every PHP endpoint enforces strict POST methodology payload validations and responds with Content-Type: application/json.

Endpoint Route Description Payload Structure
POST /api/save_app.php Add/Update Dashboard Cards {id, title, folder, description, icon, color, link, enabled, order, isToggle?}
POST /api/delete_app.php Removes object from grid permanently {id: "string"}
POST /api/upload_announcement.php Form-data handler for binary file injections FormData(image: File, type, title, subtitle)
POST /api/save_weather.php Global configuration updates (weather/animations) {weather_enabled: Boolean, background_enabled: Boolean}
