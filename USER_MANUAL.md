# User Manual: La Rose Noire Facilities Portal

## 1. Introduction
Welcome to the La Rose Noire Facilities Portal. This guide will help you navigate the user interface and understand the features available in the Admin Panel.

## 2. User Portal Guide
The main portal is designed for ease of use and quick access to all facility-related applications.

### 2.1 Dashboard Overview
- **Main Grid**: The center of the screen displays all available applications. Apps can be individual items or grouped into folders.
- **Folders**: Click on a folder card to expand it and view the applications inside. Click the "X" or outside the folder to close it.
- **Announcements Banner**: Important announcements appear at the top of the screen. You can close them by clicking the "X" icon.

### 2.2 Sidebar Features
- **Left Sidebar**:
  - **Company Branding**: Displays the LRN logo.
  - **Weather Widget**: Shows the current weather in Mabalacat City.
  - **Admin Login**: A secure link for administrators to access the control panel.
  - **Information & Logos**: Additional announcements or company logos may appear here.
- **Right Sidebar**:
  - **Calendar**: Interactive monthly calendar.
  - **Holidays**: Lists upcoming Philippine holidays for easy reference.

## 3. Admin Panel Guide
The Admin Panel allows authorized personnel to manage the portal's content, applications, and settings.

### 3.1 Accessing the Admin Panel
1. Click the "Admin Login" button on the left sidebar of the main portal.
2. Enter your secure credentials to log in.

### 3.2 Managing Announcements
The **Announcements** tab lets you control the main banner at the top of the portal.
- **Active**: Toggle the checkbox to Show/Hide the announcement banner on the portal.
- **Edit**: Update the Title and Message fields.
- **Save**: Click "Save Announcement" to apply changes immediately.

### 3.3 Managing Left Panel
The **Left Panel** tab controls the sidebar widgets and sidebar-specific announcements.
- **General Settings**:
  - **Weather Widget**: Toggle to show/hide the Mabalacat City weather display.
  - **2D Floating Background**: Toggle to enable/disable the animated floating background effect.
- **Panel Announcements**:
  - **Add**: Click "Add Announcement" to create a new sidebar item (Image or Text).
  - **Edit/Delete**: Use the actions on each item to modify or remove it.

### 3.4 Managing Apps
The **Apps** tab is where you manage the applications displayed on the main grid.
- **Add New App**: Click to open the creation form.
  - **Title**: Name of the application.
  - **Folder**: Assign to an existing folder or type a new folder name. Leave empty for root-level apps.
  - **Icon & Color**: Select a visual icon and color theme.
  - **Link URL**: The destination URL (e.g., `https://google.com` or local path).
  - **Description**: A short description appearing on the card.
- **Edit/Delete**: Use the buttons next to each app in the list to update details or remove the app.
- **Enable/Disable**: Quickly toggle an app's visibility without deleting it.

### 3.5 Managing Folders
The **Folders** tab helps organize apps into groups.
- **Create Folder**: Add a new folder container.
- **Manage Folders**:
  - **Enable/Disable**: Hide a folder and all its contents without deleting.
  - **Edit**: Rename the folder.
  - **Delete**: Remove the folder.
