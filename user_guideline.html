1. Introduction

The La Rose Noire Facilities Portal is designed to streamline day-to-day operations and provide quick access to essential tools. Whether you're an employee looking for reporting apps or an administrator managing content, this guide covers everything you need to know.

2. User Portal Guide

2.1 Dashboard Overview

The main portal dashboard provides a high-level view of available tools.

  • Main Grid: Displays applications as interactive cards. Each card contains the app name, icon, theme color, and a brief description.
  • Folders: To maintain organization, related apps are grouped into folders. Clicking a folder opens an overlay displaying its contents.
  • Announcements Banner: Critical alerts or welcome messages appear in a sliding banner at the top. These can be dismissed using the "X" button once read.

2.2 Sidebar Features

Left Sidebar

  • Weather Widget: Real-time Mabalacat City weather updates.
  • Admin Login: Entry point for site administrators.
  • Panel Communications: Displays images or text notifications from management.

Right Sidebar

  • Interactive Calendar: View current month and navigate dates.
  • Holiday List: Tracking Philippine holidays to keep you informed of upcoming events.
